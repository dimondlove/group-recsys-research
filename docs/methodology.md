# Методика эксперимента (черновик для раздела статьи «Экспериментальная установка»)

## Конвейер

1. **Данные:** MovieLens 1M (пользователи с не менее чем 20 оценками). Оценки 1-5.
2. **Разбиение:** для каждого пользователя случайно (или по времени) 20% оценок откладываются в тест; не менее 5 оценок остаётся в обучении. Seed фиксирован в конфиге.
3. **Индивидуальная модель:** матричная факторизация с учётом смещений (mu + b_u + b_i + p_u·q_i), обучение ALS-WR. Качество модели (RMSE на тесте) записывается в `meta.json` каждого запуска и приводится в статье.
4. **Группы:** формируются синтетически из пула подходящих пользователей (не менее `min_test_relevant` релевантных тестовых оценок). Схожесть: косинус между центрированными обучающими векторами оценок. Типы: `random`, `similar`, `dissimilar` (жадный подбор участников из окрестности затравочного пользователя). **Реально полученная схожесть записывается для каждой группы** (`cohesion_sim`), так же как согласованность предсказаний (`cohesion_pred`, средний Спирмен).
5. **Кандидаты:** элементы, которых никто из группы не видел в обучении.
   - `unseen_test_union` (основной): дополнительно у хотя бы одного участника есть отложенная оценка этого элемента. Плотная оценка, но результат зависит от смещения тестовых данных.
   - `unseen` (проверка устойчивости): все невиденные группой элементы. Оценка очень разрежена (большинство участников получают NDCG = 0), поэтому различия между правилами тонут в шуме.
   Рекомендуется приводить в статье основной режим и подтверждать вывод во втором.
6. **Агрегация:** правило применяется к предсказанным оценкам участников по кандидатам, берётся список из k элементов. Ничьи по очкам разрешаются по среднему предсказанию, затем по индексу элемента (детерминированно).
7. **Метрики (по отложенным оценкам):** релевантно = оценка >= 4. Для каждого участника NDCG@k (идеальный список строится из его релевантных элементов среди кандидатов) и hit. Участник без релевантных кандидатов не оценивается. По группе: средний NDCG, минимальный NDCG, коэффициент Джини NDCG, доля участников с NDCG = 0.
8. **Статистика:** по каждой конфигурации (тип группы × размер × правило) среднее и 95% доверительный интервал по группам (`summary.csv`). Парные тесты (Уилкоксон, Фридман с поправкой на множественные сравнения) подключаются на следующем этапе, группы для всех правил одни и те же, значит сравнение парное.

## Воспроизводимость

Каждый запуск создаёт папку `results/runs/<имя>_<дата_время>/` с `config.yaml`, `meta.json` (seed, версии, размеры, RMSE модели, время), `results.csv` (строка = группа × правило) и `summary.csv`. Строка о запуске добавляется в `results/experiment_log.csv`. Все генераторы случайных чисел порождаются из одного seed (`SeedSequence`), повторный запуск с тем же конфигом даёт тот же `results.csv` (проверяется тестом).

## Конвенции правил агрегации

- **Копленд:** очки = победы − поражения по попарным сравнениям, учитываются только строгие предпочтения участников (равные оценки голоса не дают), при равенстве голосов ничья.
- **Борда:** очки за каждого участника = число элементов, строго худших по его оценке, плюс 0,5 за каждый элемент с равной оценкой.
- **Least Misery / Most Pleasure / Average:** минимум, максимум, среднее предсказанных оценок.

## Ограничения (обязательно описать в статье)

- Группы синтетические: в MovieLens нет реальных групп и нет «истинного» группового решения.
- Качество оценивается по индивидуальным отложенным оценкам участников; неоценённые элементы не считаются нерелевантными только в основном режиме кандидатов.
- Одна модель и один датасет в пилоте; вывод не обобщается без проверки на других.
- Предсказания модели содержат ошибку; различия правил частично отражают её распространение, а не только свойства правил.
